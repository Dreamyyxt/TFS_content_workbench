- 本机**已装剪映**，但应用名是 `/Applications/VideoFusion-macOS.app`（bundle `com.lemon.lvpro`），

- 剪映草稿目录：`~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft`
- 剪映 11.x 的草稿列表来自该目录下的 **`root_meta_info.json`**（字段 `all_draft_store`）。
  但**不需要手动去写它**——剪映运行时会自动扫描目录、收录新草稿，并回写 `draft_meta_info.json`
  （补 `draft_name` / `draft_fold_path` / `draft_root_path`）和 `root_meta_info.json`，
  还会生成 `draft_cover.jpg` + `draft_settings`。已实测通过。

  `pyJianYingDraft 0.3.0` / `pymediainfo 7.0.1` / `pillow` / `numpy` / `imageio`。

### 踩坑
- **pip 走默认 PyPI 会卡死**（下 pymediainfo 那个 7MB wheel 长时间无进展，进程被 SIGTERM）。
  换清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 后秒装。
- **pyJianYingDraft 的时间单位是个坑**：`trange(3.0)` 传数字会被当**微秒**，
  必须传字符串 `trange("3s")`，或自己 `Timerange(int(sec*1e6), int(dur*1e6))`。
  第一版草稿所有片段时长全是 0 就是这个原因。
- 该库 API 与 README 有出入：0.3.0 没有 `add_track`，是 `append_track(TrackSpec(...)) -> TrackRef`；
  `add_segment(seg, track_ref)` 要显式传轨道引用。
- `ImageDraw.textlength` 可用来做片尾文字居中。

### 交付物
- `workbench/tools/make-jianying-draft.py`：核心生成器。
  从云端 `scripts` 表读脚本（默认最新一条，可 `--script-id`）、从 `store_profile` 读门店信息；
  解析脚本文案里的「## 分镜表」Markdown 表格（时间 / 画面 / 口播 / 字幕 四列）得到分镜；
  扫描素材文件夹（图片 + 视频，按文件名自然排序）；生成 1080x1920 草稿。
- `workbench/tools/一键生成剪映草稿.command`：双击运行、可拖拽素材文件夹的傻瓜入口（已 chmod +x）。
- `workbench/tools/剪映自动成片-使用说明.md`：给运营看的说明（命名约定 / 用法 / 参数 / FAQ）。

### 生成的草稿结构
主画面（按分镜排片段，段间叠化 0.35s）/ 口播字幕（贴底，白字黑描边）/
大字贴纸（贴上，品牌浅色 + 深棕描边）/ BGM（可选，淡入 1s 淡出 2s，音量 0.28）/
片尾 3s（Pillow 生成品牌棕 #8A5A44 底图 + 店铺名 / 地址 / 两地铁 / 营业时间 / 卖点）。
