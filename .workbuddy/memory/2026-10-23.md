## 查清「换台电脑发布就变数字域名」的真正原因

把 `app.asar` 里的发布模块（`/main/server.js`）抠出来读了实现，结论不再是推测：

- `findDeployDestination({localDir, appId})`：
  - **传了 `appId`** → 直接返回 `existing-application`，**不要求本机有任何部署记录**；
  - 没传 → `findDirectoryDeployRecord(localDir)`（只读 `~/.workbuddy/cloudstudio-deploy-history/*.json`）→ 没有记录就是 `new-application`。
- `deploySite(e)`：`let i = r ? undefined : this.resolveDeployApplication(...)` —— **`appId` 一传，目录推断整段跳过**。
- `createDeployDirectoryComparer()`：路径**逐字符相同**才算同一目录（`process.platform==='win32'` 才用 inode 兜底）。
- 工具层 `checkApplicationAvailable(appId)`：应用不可用会**报错中止**，不会退回新建。
- 所以：git 只带代码，应用归属（`.genie` 标记 / 部署历史 / 路径哈希）全在本机 → 新电脑 = 无 appId = 新应用 = 数字域名。**结论：任意机器发布都要显式传 `appId`。**

## 自动发布流水线（push → 自动上线）

**为什么分两层**：发布接口 `cloudApi.request('/applications/publish')` 带 `Access-Token`/`Client-Id`/`Open-Id`，token 由客户端 tokenManager 自刷新 → 纯 shell 拿不到，硬抄一升级就废。所以：

| 层 | 实现 | 频率 |
|---|---|---|
| 拉取+体检+重启 | `tools/auto-sync.sh`（LaunchAgent `com.wujiseason.auto-sync`） | 每 120s |
| 真正发布上线 | WorkBuddy 定时任务 `66d85765-54da-43e0-966e-c82cd84c87a0`「自动发布上线（第五季内容工作台）」 | 每小时 |

交接物：`~/.wujiseason/deploy-state.json` → `{lastProcessed, lastDeployed, pending:{commit,subject,status:ready|failed,note}}`。
日志：`~/.wujiseason/auto-sync.log`（>800 行自动截到 500）。单实例锁 `.auto-sync.lock`（>15 分钟视为残留）。

**安全底线（脚本内写死）**：只用 `git merge --ff-only`，**永不** reset/clean/stash/强推；有 **tracked** 未提交改动就跳过（纯 untracked 不阻塞，`merge` 遇同名自己会拒）；只在 `main` 生效；同 commit 只处理一次；体检不过绝不写 `pending`；`workbench/` 无变更（只动 docs/tools）则只拉代码不发布。

**实测（真跑，2026-10-23 21:39）**：用 `git worktree add --detach` 模拟另一台电脑 push（clone 全量仓库会被 SIGTERM 中断，worktree 共享对象库最省）→ auto-sync 检测到 `fc84f8e` → fast-forward → 识别 `workbench/` 1 文件变更 → 体检通过（5s）→ 重启服务 4191 正常 → 写 `pending(ready)`。回滚后重跑同样正确。脏守卫实测：改动 `workbench/index.html` 后跑，HEAD 不变、改动保留、日志记 `跳过：有未提交的代码改动`。

**配套脚本**：`安装自动发布.command` / `卸载自动发布.command` / `查看自动发布状态.command`；`bash tools/auto-sync.sh --dry-run` 只演算不动作。

**卡点**：`launchctl bootstrap` 仍是 `5: Input/output error`（工具进程不在 Aqua 会话，与装 jianying-connector 时同因）→ **必须用户双击「安装自动发布.command」**。plist 已生成在 `~/Library/LaunchAgents/com.wujiseason.auto-sync.plist`，双击后即可加载。
