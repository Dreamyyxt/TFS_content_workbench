# 进度看板：从统计数量到继续处理

沿用 `design/studio-hero-response` / PR #10，保留奶油暖色与新拟物样式。

## 变化

- 新增「接下来处理」：待补脚本、待补日期、待核对发布。脚本待办基于已选选题，日期与发布待办基于当前排期批次，同一内容可以在不同类别出现。
- 正文缺失的已选选题进入待补脚本；已有空脚本可打开查看，没有脚本的选题定位到拍摄辅助的对应条目。
- 未标记发布且未关联数据的排期，缺少有效拍摄或发布日期时进入待补日期。跳转会选择对应周历模式、清除账号筛选，并定位缺日期的实际条目。
- 已标记发布或计划时间已到、尚未关联数据的排期进入待核对发布，按计划时间排列。明确要求确认实际发布情况，可核对排期或打开原有数据录入表单；没有自动保存或标记发布。
- 待办先显示 6 条，可继续展开；切换分类保持键盘焦点，最后一页展开后焦点落到结果数量。空状态与减少动态效果均保留。
- 阶段概览替换不同范围相除的漏斗比例，分别显示最新素材、全部已选、全部脚本、当前排期、全部数据记录。点击可打开相应工作区。
- 待补脚本 KPI 计算实际缺少正文的已选条目；手动数据记录改称「已录入数据」。排期脚本缺失检查及角标验证真实正文，识别源脚本已删除和空正文。
- 本周统计使用上海日期。未来 7 天计划包含今天并按时间排序；有效脚本可直接查看。拍摄日期不再默认标注为上午，无效日期不进入负载列表。

本轮没有新增依赖、生成动作、迁移或云端写入。实际发布仍需要人工核对。
