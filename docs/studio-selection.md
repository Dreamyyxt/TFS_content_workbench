# 第五轮：选题与已选浮层

分支 `design/content-studio-selection` 基于第四轮的 `design/content-studio-interactions`，延续奶油白、米色、暖棕配色。

## 体验变化

- 点选单张选题时直接更新原卡片，保留焦点和位置；保存成功后只对当前卡片与数量做轻反馈，不重播整页卡片。
- 账号、关键词、最新批次和新增的“只看已选”可组合使用。筛选后的卡片在横向和纵向位置之间过渡；最多 12 张、每轴 72px、240ms。
- 已选浮层改用暖色凸起表面，显示已选总数、待写与已有脚本数量。手机使用两行布局，保留底部安全区域。
- “去写脚本”打开并定位到第一条待写选题；如果全部已有脚本，则定位第一条已选选题，不自动生成内容。
- 原有动效开关与系统减少动态效果偏好继续生效。

## 保存反馈

按钮在请求期间显示“保存中”，保留键盘焦点并阻止同一选题重复提交。页面保留此前状态，收到成功响应后才更新选择及数量；错误、空响应或网络异常都会保留原选择并提示重试。

清空已选会分别处理每条保存结果，只移除已确认成功的选择，失败项继续保留并报告数量。保存期间阻止重复清空和从浮层进入脚本，不影响页面导航；如果用户已经切换焦点，不强行把焦点拉回。

删除选题后也会同步更新浮层，避免显示已删除记录的计数。本轮未改动视频制作接口和生成服务。
