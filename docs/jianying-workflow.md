# 第五季视频制作：剪辑与生成

## 业务流程

风口采集/选题 → 拍摄辅助生成脚本 → 视频制作。
原选题、脚本、排期与复盘功能保留。脚本卡片“开始制作”带入标题、正文、账号和脚本/主题 ID。也支持导入 TXT/Markdown 或直接粘贴。

视频制作提供两种模式：

| 模式 | 必填输入 | 执行方式 | 输出 |
| --- | --- | --- | --- |
| 剪辑 | 至少一个照片或视频素材 | 本机直接调用指定上游 Jianying Skill | 可编辑剪映工程；MP4 在剪映内导出 |
| 生成 | 已确认的拍摄脚本 | 火山方舟 Seedance 视频生成 API | 自动取回 MP4，可预览和下载 |

## 使用

1. 双击项目根目录 `启动剪映制作.command`，或在 workbench 运行 `npm run jianying`，保持终端运行。
2. 打开 http://127.0.0.1:4191 ，进入“视频制作”。页面自动连接本机服务，也可以点“重新连接”。
3. 选择“剪辑”或“生成”，导入/填写脚本及相应素材，点击“开始剪辑”或“生成视频”。
4. 剪辑完成后，在任务内展开“在剪映中打开工程”，用剪映“文件 → 找回草稿”打开工程；调整导出 MP4 后可上传到对应任务预览/下载。
5. AI 生成成功后，任务显示“视频已就绪”，直接预览或下载。

本地原业务仍使用既有 WorkBuddy 云服务。公网尚未重新发布，发布后的公网网页→本机服务连接需要另行实测浏览器本地网络权限。

## 剪辑规则

直接调用 https://github.com/luoluoluo22/jianying-editor-skill 的 `JyProject`，不修改 Skill，不另建 FFmpeg 成片引擎。

- 1080×1920，默认30FPS；最多30个素材，单个≤100MB。
- 顺序剪辑，初始平均分配时长；视频从开头截取，短视频不循环，由照片补齐剩余时长。没有照片且视频不足时提示补充素材。
- 单独填写的字幕逐行平均分配；脚本与备注保存在工程的 `production-notes.md`，供人工调整。音乐、精细镜头选择和任意自然语言修改仍在剪映中处理。
- 唯一工程名称、禁止覆盖原工程；素材保存在 `.jianying-data/` 并被工程引用，不要删除。
- Mac 不自动导出 MP4，不把“工程已生成”标成“已出片”。

## 火山生成

密钥仅由服务端读取 `~/.workbuddy/volc_mediakit.key`，可用 `ARK_API_KEY` 环境变量覆盖；不进入网页、Git 或日志。虽文件名含 MediaKit，当前存放的是方舟凭证；已实测 MediaKit 不接受，而方舟鉴权成功。直接使用 `https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`，按官方流程创建、查询并下载结果。

- 默认使用用户已开通的 Doubao-Seedance-2.0（`doubao-seedance-2-0-260128`），可在“字幕与更多设置”选择 Fast、Mini或2.5。之前因 Fast 未开通而失败的任务，可以用当前选择的模型重试。
- 竖屏9:16、720P，5/10/15秒；脚本与生成要求组成提示词，要求生成音频。
- 无需素材；可选最多9张参考照片，单张<30MB、合计≤40MB，通过 Base64 传入。视频参考使用 HTTPS 公网链接，最多3段（2.0 总时长≤15秒）；本地视频用于剪辑，不能直接作为生成参考。
- 图片/视频须满足所选模型的格式、尺寸和内容限制，最终以 API 校验为准。字幕要求由模型尝试呈现，不承诺逐字准确。
- 任务 ID 持久化，重启继续查询已有任务。提交超时或进程在提交中关闭时显示“待核对提交”，不会自动重提；填写控制台中的 cgt- 任务 ID 后继续查询，避免重复计费。
- 已完成的远端任务下载失败时，重试继续查询/下载同一任务。远端任务已明确失败，手动重试才创建新任务。
- 生成任务和 MP4 保存在本机 `.jianying-data/`；尚未自动同步到云排期或复盘表。

官方说明：[视频生成 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[生成任务结果](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)。

## 验证

- 上游 Skill1.7.0 与本机剪映11.5.3（`/Applications/VideoFusion-macOS.app`）的基础图片/标题/轨道工程兼容性已实际打开验证。
- 新版网页导入 Markdown、上传照片并提交20秒剪辑任务，原生工程生成并回传成功；这次新工程未另行打开或导出。
- 火山凭证的模型列表及视频任务查询均返回200。纯脚本、零素材的5秒真实生成请求到达方舟，但返回账户尚未开通默认模型，没有成功创建视频任务。用户随后确认已开通标准 Doubao-Seedance-2.0；默认已切换到 `doubao-seedance-2-0-260128`，同一5秒纯脚本、零素材验收任务重试后成功完成，MP4 已自动保存到本机并可在任务中预览/下载。
- 自动测试4项通过：角色/来源鉴权，剪辑素材与生成脚本必填，生成成功持久化与MP4范围读取，重复提交去重，未知提交结果不自动重试，错误不包含密钥。生成成功路径使用测试替身验证。
- 浏览器无脚本错误、云数据同步正常；桌面和390px手机视口无横向溢出。导航图标与计数、表单及任务状态沿用其他页面组件。

## 运行配置

Node18+，无项目运行依赖。本机仅监听127.0.0.1:4191。网页与执行器使用不同临时令牌，只允许本机和原生产域名连接。

`JY_SKILL_ROOT`、`JY_PYTHON`、`JY_DRAFT_ROOT`、`JY_DATA_DIR` 控制剪映环境。未找到 Skill Python 时仍可运行火山生成服务，剪辑显示执行器离线。历史素材、MP4、工程和 `.video-data/` 保留。

## 进度与 Prompt 可见性

生成任务显示提交、火山生成、取回文件、可预览四个阶段，以及真实远端状态、等待/耗时、最近查询时间。页面每5秒自动更新；接口不提供百分比，因此不显示推算百分比。刷新失败会明确提示。

“查看提交 Prompt 与参数”展示模型、时长、比例、参考素材数量、远端任务 ID 和完整文本，可复制。新任务在提交前留存实际 Prompt；旧任务按原有相同模板及已保存输入还原，并标注还原说明。自动刷新保留展开的详情，已完成任务的预览不因其他任务刷新而重建。
