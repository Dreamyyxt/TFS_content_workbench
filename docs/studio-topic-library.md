# 选题库：先看开场，再展开思路

继续在 `design/studio-hero-response` / PR #10 中迭代，保留原有暖色与待制作流程。

## 变化

- 选题卡片优先展示账号、形式、标题与完整开场；角度、目标、理由和关键词放入原生可展开区域，删除入口保留原确认流程。
- 增加形式与脚本状态筛选，可与账号、关键词、只看已选组合使用。搜索包含选题理由，列表保持原顺序。
- 明确显示当前结果数量、批次范围；清除筛选会重置搜索、账号、形式、状态与只看已选，但保留「仅看最新一批」的当前设置，焦点返回搜索框。
- 账号包含当前数据中的历史账号，计数以当前批次范围为准。
- 已关联脚本的选题可直接查看脚本，关闭后焦点回到入口，不自动勾选选题。关联兼容数字和字符串 ID。
- 从日历定位旧选题时清除新筛选，保证目标可见；没有新增生成或云端写入动作。
- 手机单列布局，筛选自动换行，支持键盘与减少动态效果。

原有勾选保存、失败重试、批量清空及底部待制作面板保持原流程。
