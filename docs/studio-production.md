# 视频制作：准备清单与任务状态

沿用 `design/studio-hero-response` / PR #10，保留原有暖色与两种制作方式。

## 变化

- 提交前准备展示内容、素材/配乐与连接状态，随制作方式、脚本传入和输入更新。清单是准备提示，提交仍经过原有校验。
- 任务可按全部、制作中、待导出、成片就绪和需处理筛选，组合搜索标题、账号或制作方式；提供结果数量、清除筛选和空状态。
- 每条任务显示下一步。剪映草稿仍需在剪映内检查、导出 MP4；成片才提供预览与下载。不确定提交先核对远端任务 ID。
- 失败和待核对任务不突出显示正在执行的阶段；没有完成时间时显示创建时间。
- 筛选保留卡片，刷新保留核对输入、展开详情和同状态控件焦点。任务完成离开筛选时，焦点返回类别按钮。
- 断线时更新准备清单与连接提示，保留最后读取的任务。
- 新增内部只读展示模块 `production-workflow.js`，加入服务静态资源白名单。没有新增外部依赖，原提交、重试、上传和核对接口保持不变。

本轮没有调用剪映执行器或视频生成服务；没有生成真实草稿、打开剪映验收或导出 MP4。
