# 拍摄与发布周历

本轮将自动排期页的只读长表改成按周操作的工作区，沿用奶油白、米色和暖棕。与首页 Hero 同在 `design/studio-hero-response` / PR #10 中，没有新建项目工作副本。

## 页面与行为

- 发布安排：按周一到周日分组展示内容、上海时间、账号、对应拍摄日期和数据状态。
- 拍摄安排：只展开实际有任务的拍摄日，集中展示当天内容，可直接查看脚本或进入既有拍摄模式。
- 账号筛选、前后切周、回到本周、空周的最近排期入口。概览数量与当前视角、周和账号一致。
- 首次进入优先展示本周；本周没有当前批次安排时，展示最近的未来安排，若均已过去则展示最近一次安排。手动切换视角不会跳周。
- 保留原生成算法、写入入口与最新批次范围；生成设置收在「生成新排期」内。成功生成后重新定位到新计划。
- 卡片复用既有脚本弹窗、拍摄模式、选题定位和数据表单入口。没有自动生成、自动录入或拖动改期。
- 缺少或无效日期的内容在「日期待补」单独保留，不被静默丢弃。明确关联但已删除的脚本不会显示为可用；没有明确脚本关联时，可找到原选题后来生成的脚本。
- 计划时间已到、已标记发布、已录入数据分别展示。只有实际关联的数据记录才显示已录入。打开表单不保存记录。
- 桌面发布周历为七列；较窄窗口转为多行；手机为单列日程。拍摄安排使用按拍摄日分组的宽卡片。

## 验证

- 50 项项目测试通过，新增上海时区、两种日期分组、账号筛选、缺失日期、跨年和最近排期投影测试。
- 既有工作台浏览器回归通过：9 个页面 × 5 个宽度及选题、脚本、日历、数据表单、弹窗和动效偏好。
- 新周历专项通过：在美国设备时区下仍按上海日期展示；仅当前批次；账号与视角组合筛选；缺日期和缺来源；切周、空周与空排期；脚本关闭后焦点恢复；拍摄入口；数据表单预填；生成设置仍可访问；320–1600px 布局；减少动态效果。
- 浏览器使用隔离云 SDK，断言无未捕获异常、零云端写入。生产数据未用于测试。

运行本机工作台服务后：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node workbench/tools/planner-browser-check.cjs
```

默认地址 `http://127.0.0.1:4318`，可用 `STUDIO_URL` 替换。`STUDIO_ARTIFACT_DIR` 指定产物目录；`STUDIO_RECORD_DEMO=1` 可录屏，需要 Playwright 录屏依赖。
