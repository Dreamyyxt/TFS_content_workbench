# 拍摄模式

分支 `feat/studio-shooting-mode` 接续选题交互分支 `design/content-studio-selection`（PR #8）。

## 使用

脚本库每张卡片，以及“查看完整脚本”的弹窗，都有“拍摄模式”入口。

- 规范分镜表按每行一个镜头展示，保留时间、画面/运镜、口播、字幕及其他原始列内容。
- 左侧镜头列表可跳转；手机使用横向镜头列表。上一镜/下一镜和键盘左右方向键只切换阅读位置。
- “标记这一镜已拍”独立操作，可再次点击撤销。全部标记后显示清单完成提示，仍可继续查看、撤销。
- 标准、大字、特大三档字号；长文在阅读区域内滚动，底部操作栏保持可见。
- Esc 退出并返回原入口。从完整脚本进入时，退出拍摄后仍可继续阅读完整脚本。
- 空脚本入口禁用。没有可识别的分镜表，或表格行不完整时，保留全部原文并按段落阅读，明确使用“段”和“完成”标记，不把发布配置推断成镜头。

## 进度保存与范围

镜头位置、已拍标记和字号按工作台及脚本 ID 存在当前浏览器的 localStorage，刷新后可恢复，不跨设备同步。记录包含用于校验版本的原脚本内容；脚本内容改变后显示提示并重置旧进度，防止错用拍摄标记。

存储不可用或空间不足时显示提示，退回本次页面打开期间的内存进度。拍摄标记是用户维护的清单，不修改脚本正文、云端排期或视频制作状态。

解析不调用模型，不补写画面或台词；内容以纯文本显示。分镜表可以包含转义的竖线、代码片段和 `<br>` 换行；无法可靠拆分时回退原文。

## 验证

- `node --test workbench/tests/*.test.cjs`：48 项通过，含 5 项新增解析/进度恢复测试。
- 保留原有浏览器验收：9 页 × 5 种宽度，以及选题、脚本、日历、图表、制作模式与动效开关。
- 拍摄专项：规范分镜、旧格式、空脚本、标记/撤销、独立翻页、三档字号、刷新恢复、版本重置、脚本隔离、存储拒绝、嵌套弹窗焦点与 Esc、减少动效、切镜时关闭的动画清理。
- 检查 390×844、320×568、844×390、1440×1000 下横向溢出、阅读区域高度与操作按钮可见性。
- 专项验收断言零云端写入，无未捕获脚本错误。

启动 `workbench` 静态预览（默认本机 4318 端口）后：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright STUDIO_ARTIFACT_DIR=/tmp/shooting-check node workbench/tools/shooting-browser-check.cjs
```

加 `STUDIO_RECORD_DEMO=1` 可录屏。两个浏览器验收脚本共用 `workbench/tools/studio-fixture.cjs` 的隔离 SDK 与示例数据。
