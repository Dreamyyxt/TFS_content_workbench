# 内容工作台视觉改版

分支：`design/content-studio-refresh`。本次在本地分支实现，未发布线上。

保留第五季原有的奶油白、米色、暖棕品牌色。借鉴参考笔记的圆形流程节点、凸起与凹陷的表面、布局层次和轻微呼吸动画，没有采用银灰或珊瑚红配色。动效遵守系统减少动态效果设置。

## 交付

- 新增创作工作台首页：选题、脚本、制作、排期四个入口连接中心造型；概览、待办和账号矩阵来自现有云端记录。加载中与连接失败使用明确状态，不伪造计数。
- 选题库增加搜索，支持标题、关键词、账号、角度、钩子；与原有账号和批次筛选共同生效。选题按钮支持键盘操作，并实时更新底部选题篮。
- 数据看板增加按发布日期汇总的播放柱图和平均 3 秒完播率圆环；统计、图表、明细、排名使用同一账号筛选。柱图展示最近七个有记录的发布日期及这些作品当前播放量，并非每日新增播放量。
- 全部页面沿用统一暖色拟物样式，保留风口选题 → 拍摄辅助/脚本 → 视频制作，以及排期、进度、复盘、档案、数据管理。
- 未改动剪映 Skill、制作服务、火山 API、凭证存储、已有素材或工程。

## 验证

- `node --test tests/*.test.cjs`：20 项通过。
- `node --check app.js` 和 `git diff --check`：通过。
- 浏览器：选题搜索与勾选、选题篮计数、首页计数、脚本带入制作、两种视频模式、账号筛选联动、无数据状态、录入表单打开/取消、减少动效设置，无未捕获 JavaScript 错误。
- 9 个页面 × 5 种视口宽度（1440、1024、768、390、320px）无页面横向溢出。明细表在窄屏内横向滚动。

浏览器回归脚本：`workbench/tools/studio-browser-check.cjs`。需要本机 Chrome 和可解析的 Playwright 模块；可用 `PLAYWRIGHT_MODULE` 指定已有模块的绝对路径。启动静态预览后运行：

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory workbench
# 另一个终端，仓库根目录：
node workbench/tools/studio-browser-check.cjs
```

可用 `STUDIO_URL` 指定预览地址、`STUDIO_ARTIFACT_DIR` 指定测试截图目录。脚本拦截云 SDK 并阻断其他外部请求，不写入云端，不调用视频生成。
