# 风口选题：Discover / Create

分支 `design/discover-create`，从最新 `origin/main`（`d2ec892`）创建。包含主分支已有的远程访问和上传修复，不回退上一阶段发布内容。

## 结构

- Discover 选题：关注主题、添加/保存、数据源设置、获取风向，以及可独立收缩的本期风向结果，共用一个主容器。
- Create 生成：按账号生成入口、生成状态、主题库搜索与筛选、主题卡片，共用第二个主容器。示例选题入口归在主题库。
- 采集进度显示在 Discover，生成进度显示在 Create；继续使用同一流式进度组件，按动作移动到对应容器，不增添模型或数据库调用。
- 风向折叠保留本地偏好，添加 `aria-expanded` / `aria-controls` 和隐藏状态；折叠不隐藏关注主题或操作。手动重新采集会展开结果。

## 视觉

- 移除关注主题、账号生成、主题库工具栏的嵌套面板，只用间距及细分隔线建立层级。
- 开场与选题理由不再使用实心色块；来源主题摘要也改成平铺文字。
- 主题卡片的账号、形式、重点统一字号、最小高度与中性色，不再按账号铺多种色块。
- 已有/待写脚本统一用文字；查看脚本与状态同排。加入待制作固定为底部等高整行按钮，选中只强调边线和按钮，不染满整张卡片。
- 删除入口继续直接可见，保留原确认流程；长短标题、展开详情仍按行对齐。
- 样式限制在风口选题页，保留第五季原版 logo 和暖棕色系。

## 验证

72 项 Node 测试通过；适配现有采集测试的 DOM 模拟以支持进度容器移动。原风向/生成专项、主题库专项（7 宽度）、全站 9 页 × 5 宽度回归通过。临时浏览器检查另验证两个主容器的内容归属、结果折叠与刷新保留、关注主题始终可见、6 种宽度下标签尺寸/颜色一致、开场透明背景、整行选择按钮及删除取消。

使用模拟数据库、搜索和模型，无真实采集、付费调用或线上写入。预览：`outputs/discover-create/preview.html`。前端变更仅 `index.html`、`app.js` 和 `studio.css`，无数据迁移或接口变化；尚未合并或发布。
