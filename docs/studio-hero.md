# 首页 Hero：球体与模块联动

分支 `design/studio-hero-response` 直接在原主目录迭代。保留奶油白、米色和暖棕，以及原有虚线流动连接。

## 交互

固定浅色圆框，去除两段对称的棕色弧线和整体旋转。球体内部与柔光随选中模块一起变化：

- 风口选题：花瓣向外舒展，形态更饱满。
- 拍摄辅助：花瓣收束，形态更紧密。
- 视频制作：花瓣横向舒展，保持轻柔呼吸。
- 发布日历：花瓣收为圆润、规整的姿态，柔光落在右下。

球体亮面与框内柔光按实际节点位置移动，窗口缩放后重新计算。外框与标题保持稳定，鼠标视差只作用于内部球体。切换模块时，球心轻轻放大回落，扩散一次淡色涟漪；快速切换会取消上次回应，避免叠加。待机只保留轻柔的浮动和呼吸。中心下方显示正在关联的模块名。

鼠标悬停、键盘焦点都能触发联动。鼠标移到新模块时优先回应鼠标，避免被旧的键盘焦点覆盖；重新用键盘移动焦点后恢复键盘控制。在节点之间移动时保持反馈，离开流程区域且没有节点焦点后恢复待机。

模块卡片随选中状态受光，圆钮出现淡暖光圈，箭头轻移；按下时卡片与圆钮轻微下沉，按钮命中区域不移动。模块标题切换有 220ms 的淡入过渡。虚线按球体与圆钮的实际位置重算，窗口缩放、数量变化引起卡片尺寸变化及返回首页时都会更新，保持原来的曲线与流动样式。

模块点击仍立即进入原页面。离开首页时暂停装饰动画；动效开关和系统减少动态效果继续生效，关闭时保留静态形态和对应关系。

## 验证

- 48 项项目测试通过。
- 本轮原有浏览器验收通过：9 页 × 5 种宽度，选题、脚本、日历、图表、制作模式、阅读弹窗与动效偏好。
- Hero 专项：四种内部姿态、模块名与虚线一致，柔光方向与节点几何位置一致，圆框固定且没有对称弧线，快速切换只有一次可取消涟漪，鼠标与键盘交替控制，响应缩放与连线端点（320–1440px），按压反馈且命中区域稳定，离开首页暂停呼吸，恢复待机，减少动态效果、立即导航、离线预览。
- 使用真实 Node 工作台服务进行资源加载和页面验收，云 SDK 使用隔离示例数据；断言零云端写入、无未捕获异常。

专项运行：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright STUDIO_ARTIFACT_DIR=/tmp/hero-check node workbench/tools/hero-browser-check.cjs
```

默认本机预览 `http://127.0.0.1:4318`；加 `STUDIO_RECORD_DEMO=1` 可录屏，需要 Playwright 屏幕录制依赖。

本轮合并了已有本地与远端静态资源白名单修复，并保留远端新增的发布流程。Hero 没有新增运行时脚本，继续使用已注册的 `studio-motion.js`。
