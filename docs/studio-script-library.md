# 脚本库：从原文截断到分镜预览

继续在 `design/studio-hero-response` / PR #10 中迭代，保留原有暖色与选题、脚本、拍摄、制作流程。

## 变化

- 卡片首先展示账号、时长、上海时区创建日期、标题与原有状态。
- 复用 `ShootingPlan.parse`：规范分镜表展示前两镜的时间、画面和口播，以及真实镜头总数。没有可识别分镜或表格异常时显示原文摘录，不推断镜头。
- 常用操作分为「查看完整脚本」「拍摄模式」「开始制作」。自检详情、替换和删除集中到可展开的「自检与管理」；风险标签和提示数量在折叠时仍可见，确认流程保留。
- 空脚本显示「暂无正文」，拍摄入口保持禁用。不会将空正文标为已通过检查。
- 新增最近创建、最早创建、标题顺序排序，与搜索、账号、状态组合使用。未知或非法创建日期始终置后，同值保持原顺序。
- 新增一键清除筛选和无结果恢复入口；重置搜索、账号与状态，保留排序，焦点回到搜索框。
- 手机分镜预览纵向排列；左侧已有脚本的选题保持可读，不再整体降低透明度。

卡片预览只读，不改写脚本、不生成内容、不写入云端。完整脚本保留原文。
