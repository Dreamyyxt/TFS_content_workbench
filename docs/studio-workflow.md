# 第三轮：选题、脚本与发布日历

分支 `design/content-studio-workflow` 接续动效分支 `design/content-studio-motion`。保留现有奶油白、米色与暖棕配色。

## 交互变化

- 首页的“去写脚本”会打开并聚焦对应选题。未勾选的历史选题从日历打开时，会自动解除选题页筛选并定位原卡片，不会自动勾选或生成。
- 脚本库支持标题、正文和账号搜索，可组合账号与全部、未排期、已排期、需检查筛选。排期状态按当前批次的明确脚本关联判断，不代表视频已制作完成。
- 选题侧栏显示待写与已有脚本数量，可只看还没写脚本的选题。
- 首页周日历显示当前批次的发布计划，可切换周和日期。日期与时间统一使用上海时区；缺少或无效日期的计划不进入日历。
- 日历可查看原脚本；来源已删除时给出说明。只有明确关联的数据记录显示“已录入数据”，不会根据标题或计划时间推断完成。
- 到时间的计划可进入录入表单，带入排期、账号、平台、标题与发布日期；已有记录则打开编辑表单。打开、取消都不会创建记录，仍需用户保存。
- 恢复连接后重新读取数据会正确恢复首页加载状态。

日历沿用既有“最新批次”的排期范围，不汇总被替换的旧计划。
