# 数据看板：从复盘范围到创作回溯

继续使用 `design/studio-hero-response` / PR #10 和原有暖色新拟物样式。

## 行为

- 集中的复盘范围支持全部时间、近 7 天、近 30 天与未填日期。最近范围以上海日期为准，包含今天和起始日，不包含未来日期；无效或未填写日期可单独查看，全部时间保留所有记录。
- 搜索标题、账号、平台和备注，可与时间、账号组合。账号选项包含历史记录中的账号。
- KPI、播放图、完播环、明细与选题回溯使用同一份筛选结果。播放图继续展示范围内最近 7 个有效发布日期，未填日期不伪造图表点。
- 明细支持最近发布、播放量优先、3 秒完播优先。缺失或无效排序值置后，真实 0 保留，同分保持原顺序，不改动原数据。
- 清除筛选重置时间、账号和搜索，保留明细排序，焦点返回搜索框。无结果时也提供恢复入口。
- 选题回溯沿「数据记录 → 已关联排期 → 选题 / 脚本」查找真实内容；兼容数字和字符串 ID。来源删除或没有关联时明确提示，不按标题猜测，不生成内容、不修改选题状态。
- 修复明细编辑、删除入口强转数字 ID 的问题，使用原始记录 ID。保留原表单与删除确认。
- 手机筛选分行显示；明细区域可聚焦、键盘横向滚动。日期包含年份，避免不同年度混淆。

没有新增依赖或数据迁移，筛选、排序与回溯均只读。原有指标计算、数据录入保存流程和参考线保持不变。
