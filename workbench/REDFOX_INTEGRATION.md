# 红狐风向采集

红狐与公开网页采集并行，任一采集失败不阻断另一个。两者均无可用作品时读取已有云端风向，不生成空依据的新计划。

店铺档案 → 账号矩阵 → 风向采集关键词：逗号分隔；留空按账号内容定位选择作品、经营或日常类关键词。最多24个关键词。账号配置仍同步现有云端。

红狐 MCP 返回结果在服务端按发布日期限制近7天，再去重和计算标签参考分数。日期未知、过期及明显未来时间剔除并计数；支持Unix秒、毫秒和日期字符串。搜索目前只读取接口第一页，日期过滤可能留下很少甚至零条，不能理解为平台没有相关内容。红狐返回的关联词笔记数量不是搜索量；累计点赞不是增长速度。

抖音 MCP 搜索工具失败时尝试 REST；小红书失败单独报告。页面通过 NDJSON 显示平台、关键词和当前操作，并在云端快照保存部分失败原因及剔除数量。

同一密钥、关键词和时间窗的成功完整结果缓存10分钟。重复并发请求合并；失败或部分失败结果不缓存。缓存仅在服务进程内存，重启清空，不共享到其他服务实例；密钥不存进缓存键（使用SHA256摘要）。

已有浏览器密钥继续有效。部署服务可设置 REDFOX_API_KEY 环境变量供连接同一服务的设备使用，前端只查询“是否配置”，不会拿到服务端密钥。浏览器已配置密钥优先于服务端密钥。没有把浏览器现有密钥自动迁移到服务器；不同机器运行各自本机服务也不会自动共享密钥。

验证：自动测试覆盖时效、未知/未来日期、时间戳、账号关键词、缓存隔离/合并、失败不缓存、MCP工具失败转REST和部分平台失败；浏览器模拟流式响应验证分段JSON和进度。不使用真实付费采集进行测试。
