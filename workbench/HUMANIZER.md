# 中文口播「去 AI 味」（L3：固化进提示词）

## 这是什么

工作台生成脚本和选题时，会把一份「去 AI 味写作纪律」拼进提示词，
让每一篇出厂就带人味，而不是事后人工返工。

规则文件：`humanizer-policy.js`（浏览器与 Node 共用，挂 `window.HumanizerPolicy`）。

来源：框架取自 [humanizer](https://github.com/blader/humanizer)（MIT），
它依据的是维基百科 [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)
里编辑们总结的 24 条英文 AI 腔特征。**那份是英文语料，中文短视频口播里最常见的 AI 腔它抓不到一半**，
所以这里做了本地化：只留对中文口播真正有效的条目，另补中文特有的一批。

## 怎么生效（三个接入点）

| 位置 | 作用 |
|---|---|
| `scriptPrompt()` | 每支分镜脚本的提示词里，按账号插入对应语气的规则块 |
| `refreshPrompt()` | 每周选题的标题 / 钩子 / 角度，同样过一份规则（scope 为 `plan`） |
| 生成后的卡片与提示 | 对成品做一次自检，命中就在卡片上标出来（只提示，不改写、不阻断） |

`corpusPrompt()` 不接——那一段是喂给模型判断风向的原始材料，不是产出文案。

## 规则口径（要调就改这里）

一、出现即算失败：否定对举（不是……而是……）、结尾拔高上价值、空话套话
（值得一提的是 / 总而言之）、互联网黑话（赋能 / 闭环 / 抓手 / 颗粒度 / 心智）、
万能赞美（极致 / 完美 / 惊艳 / 氛围感 / 质感拉满）、广告腔（每一次 / 只为 /
专属于你 / 宠爱）、新闻腔（标志着 / 见证了）、破折号与加粗当装饰。

二、必须做到：短句打底长短交替；每句带具体东西（款式名 / 颜色 / 部位 / 时长 /
手上动作 / 对话原话 / 真实场景）；允许语气词、停顿、自问自答；允许有态度。

三、红线（优先于以上全部）：**不新增事实**——价格 / 地址 / 款式 / 客人 / 数据只能
来自给定材料；不改分镜表结构、镜头数、时间轴与总时长；不引入违规词。

按账号的语气分级（`VOICE`）：

| 账号 | 语气 |
|---|---|
| 抖音官方号 | 干净克制，画面是主角，一句短介绍就够 |
| 小红书官方号 | 像懂行的朋友在讲，讲取舍理由，不堆术语 |
| 老板IP号 | 最像聊天，允许口头禅、半句跑题、自嘲 |
| 店铺日常号 | 短、碎、有现场感，可以只说半句 |

## 自检表与产出

`scan(text)` 分三级：

- `hard`：基本可判定 AI 腔（否定对举、结尾拔高、空话、黑话、新闻腔）
- `soft`：偏广告腔 / 套话，看账号语境（万能赞美、广告腔）
- `layout`：纯排版特征（破折号、加粗）——分镜表里会正常出现，
  **只在提示词里约束，不计入卡片提示**，避免噪音

卡片上显示的「去AI味：xxx×N」只统计 `hard` + `soft`。

## 已知边界

- 规则是**约束**，不是保证。模型偶尔仍会踩；这时靠卡片自检发现，人工改一句即可。
- 英文那 24 条里的时态、冠词、Title Case 等条目对中文无效，已剔除。
- 想调整力度（更口语 / 更克制），改 `humanizer-policy.js` 的 `rules()` 与 `VOICE` 即可，
  改完**必须重新同步镜像并发布**，否则线上仍是旧口径。
