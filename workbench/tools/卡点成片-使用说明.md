# 第五季 · 卡点成片（本地全自动）

> 给一堆图片和视频 + 一首 BGM → 自动出带转场、踩在拍子上的竖版成片。
> **不需要剪映，不需要云 API，不需要联网，零成本。**

---

## 一句话结论

| 方案 | 成本 | 自动化 | 卡点精度 | 转场 | 前置条件 |
|---|---|---|---|---|---|
| **本地卡点引擎（本文档）** | **0 元** | **全自动** | **按真实节拍算，±23ms** | **57 种真转场** | 素材 + BGM |
| 火山 MediaKit | 0.06 元/分钟 | 全自动 | 要自己算好每段时长 | 有 | 需 API Key（已接入，后付费） |
| 剪映「模板换素材」 | 0 元 | 半自动 | 模板自带 | 剪映级 | 模板草稿（受剪映加密限制） |
| 手工在剪映剪 | 0 元 | 手工 | 手拉 | 剪映级 | 时间 |

**日常用第一个。** 它的短板只有一个：花字、贴纸、字体动效这类**设计感**不如剪映官方模板——
需要更花哨的排版时，用它出干净的画面，再进剪映加一层就行（两条路不冲突）。

## 快速开始

```bash
PY=/Users/dreamyyxt/.workbuddy/binaries/python/envs/default/bin/python
cd /Users/dreamyyxt/WorkBuddy/2026-10-05-12-31-27

# ① 只看编排方案，不渲染（先确认节奏对不对）
$PY workbench/tools/make-beat-video.py \
    --media "第五季图片/我的素材" \
    --bgm   "第五季图片/bgm.mp3" \
    --plan

# ② 渲染成片
$PY workbench/tools/make-beat-video.py \
    --media "第五季图片/我的素材" \
    --bgm   "第五季图片/bgm.mp3" \
    --out   "outputs/抖音-0725卡点.mp4"

# ③ 加开场标题 + 店铺片尾卡
$PY workbench/tools/make-beat-video.py \
    --media "第五季图片/我的素材" \
    --bgm   "第五季图片/bgm.mp3" \
    --title "静安·第五季美甲美睫\n一个客人 一个设计" \
    --endcard 3 \
    --out   "outputs/抖音-0725卡点.mp4"
```

素材也可以直接点名单个文件，不用建文件夹：

```bash
--media "a.jpg,b.mp4,c.png"
```

## 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--media` | 必填 | 素材文件夹 / 逗号分隔的文件 / glob 通配 |
| `--bgm` | 必填 | 背景音乐（mp3 / m4a / wav / flac） |
| `--out` | — | 输出 mp4；不加则必须配 `--plan` |
| `--every N` | 自动 | 每 N 拍切一次画面。数字越大越舒缓 |
| `--intro-shots` / `--intro-every` | 0 / 4 | 前几个镜头用更慢的密度，做"渐入" |
| `--style` | `soft` | 转场风格：`soft`(高端安静) / `punchy`(带节奏) / `hard` |
| `--transitions` | — | 自定义转场名逗号分隔，覆盖 `--style` |
| `--fade` | 自动 | 转场时长秒。默认按最短镜头自适应（0.14–0.34s） |
| `--motion` | `auto` | 图片动效：`auto` / `zoom-in` / `zoom-out` / `pan-right` / `pan-left` / `none` |
| `--image-fit` | `auto` | 图片怎么摆进竖版：`auto` / `pad`(留白居中) / `blur`(模糊背景) / `crop`(裁切填满) |
| `--video-mode` | `auto` | 视频处理：`auto` / `speed`(变速适配) / `trim`(裁中间段) / `loop`(循环补足) |
| `--length N` | 全曲 | 只取 BGM 前 N 秒 |
| `--start N` | 0 | 从 BGM 第 N 秒开始用 |
| `--endcard N` | 0 | 结尾加 N 秒店铺片尾卡（自动读店铺档案） |
| `--title "文字"` | — | 开场大字标题，`\n` 换行 |
| `--title-dur` / `--title-size` / `--title-y` | 2.6 / 66 / 0.66 | 标题停留秒数 / 字号 / 纵向位置 |
| `--max-loops N` | 2 | 每个素材最多出现几次（防止一张图闪十几次） |
| `--order` | `name` | 素材顺序：`name` / `shuffle`(打乱) / `size` |
| `--volume` | 1.0 | BGM 音量倍数 |
| `--plan` | — | 只打印编排方案 |
| `--keep-temp` | — | 保留中间文件，排查问题用 |

## 它是怎么卡上点的

1. **分析 BGM**：用 librosa 做节拍跟踪，得到 BPM 和每一个拍点的秒数（实测精度 ±23ms，约一帧）
2. **排镜头**：切点**全部落在真实拍点上**，所以画面切换天然踩拍，不是"看着差不多"
   - 开场镜头从 0 拉到第一个切点，比常规镜头略长，读起来像开场
   - 收尾那段太短就并进前一镜，保证 BGM 完整放完、不被硬切
   - 镜头太长会均分、太短会并进相邻镜头
3. **自动选密度**：你不指定 `--every` 时，它会算出「素材数 × `--max-loops`」能撑住的最紧密度
   —— 所以给 5 张图它不会切成 40 个镜头让每张图闪 8 次
4. **每段先渲成标准片段**：图片加肯·伯恩斯推近/平移，视频按需要变速或裁中间段
5. **串联**：用 ffmpeg `xfade` 做真转场。每段多渲一个转场时长，让重叠后**累计时长仍精确等于拍点**，不会越走越偏
6. **音频对齐**：BGM 裁到片长、带淡入淡出，直接封装

## 图片会自动判断怎么摆

引擎会采样图片四边的像素，判断它是什么类型，然后选合适的摆法：

| 判定依据 | 结果 | 适用 |
|---|---|---|
| 边框颜色干净（离散度 < 20） | **留白居中**，用图自己的底色补边 | LOGO、品牌卡片、带文字的图 |
| 边框杂乱，且比例接近 9:16 | **裁切填满** | 手机竖拍的实拍照片 |
| 边框杂乱，比例差得多 | **模糊背景填满** | 横拍的实拍照片、相机原片 |

留白类图片会先把内容收进 90% 安全区再让动效在安全区外裁切，所以**推近时不会切到文字和 logo 边缘**。

强制指定：`--image-fit pad|blur|crop`

## 素材怎么准备最省事

- **图片**：4–10 张。竖版最好；横版也行（会自动上模糊背景）。LOGO 可以混在里面
- **视频**：每段 3 秒以上就够。引擎会按镜头需要变速或裁中间段，**不会**出现定格黑场
- **BGM**：鼓点清晰的更好识别
  - ⚠️ **版权**：发抖音请用抖音自身的音乐库、或剪映音乐库里的免版权曲目。别用商业歌曲原曲
- 素材文件名按顺序命名（`01_xx.jpg` `02_xx.mp4`），引擎默认按文件名排序

## 输出规格

| 项 | 值 |
|---|---|
| 分辨率 / 帧率 | 1080×1920 竖版 / 30fps |
| 编码 | H.264 High，CRF 16，preset slow |
| 码率 | 实际约 4–6 Mbps（抖音 1080p 推荐量级） |
| 色彩 | yuv420p，bt709 有限色域（标准交付格式） |
| 音频 | AAC 192kbps |
| 封装 | MP4 + faststart |

> 参考：早前那支品牌片预览只有 361 kb/s，现在这套是它的 10 倍以上，画面不会糊。

## 常见问题

**Q：检测不出节拍 / 卡不上点？**
说明 BGM 鼓点太弱（钢琴、纯人声最容易这样）。换一首节奏明确的，或手动指定 `--every`（比如 4 拍切一次）。

**Q：镜头切得太快 / 太慢？**
调 `--every`。BPM 100、`--every 4` ≈ 每 2.4 秒切一次；`--every 2` ≈ 每 1.2 秒。
也可以用 `--intro-shots 3 --intro-every 8` 让开头慢下来再进入节奏。

**Q：同一张图出现太多次？**
调小 `--max-loops`（默认 2），或者多用几张素材、缩短 `--length`。

**Q：视频片段看着怪？**
默认 `--video-mode auto` 会在 ±2 倍速内变速适配，超出就改裁切/循环。
想完全不动速就设 `--video-mode trim`。

**Q：转场太花 / 太素？**
`--style soft`（默认，柔和）/ `punchy`（带节奏）/ `hard`（快闪）。
也可以 `--transitions dissolve,fade,smoothleft` 点名。

**Q：想再进剪映精修？**
这条工具出的是成品 MP4。如果想在剪映里调，可以用 `make-jianying-draft.py` 走草稿那条路
（见 `剪映自动成片-使用说明.md`）。两条路输出的时长与编排一致。
