# 云端成片 · 使用说明（火山引擎 AI MediaKit）

一句话：**素材文件夹丢进去 → 云端渲染 → 拿回一支带专业转场和镜头运动的成片。**
不用开剪映，不用等本地渲染。

---

## 一、先开通（一次性，约 10 分钟）

1. **注册火山引擎账号**
   https://console.volcengine.com/
   注册后按提示做**实名认证**（个人认证即可）。

2. **开通 AI MediaKit**
   打开 https://console.volcengine.com/imp/ai-mediakit
   按控制台提示确认开通协议。首次开通有免费试用额度，之后按量计费。

3. **创建 API Key**
   打开 https://console.volcengine.com/imp/ai-mediakit/settings
   点「创建 API Key」→ 复制出来（**只显示一次，先存好**）。

4. **把 Key 配到本机**（任选一种）

   ```bash
   # 方式 A：环境变量（本次终端有效）
   export MEDIAKIT_API_KEY=你的Key

   # 方式 B：存成文件（长期有效，推荐）
   mkdir -p ~/.workbuddy
   echo '你的Key' > ~/.workbuddy/volc_mediakit.key
   ```

5. **自检**
   ```bash
   PY=/Users/dreamyyxt/.workbuddy/binaries/python/envs/default/bin/python
   cd /Users/dreamyyxt/WorkBuddy/2026-10-05-12-31-27
   "$PY" workbench/tools/volc-mediakit.py --check
   ```
   看到「✓ 鉴权通过」就可以用了。

## 二、出片

```bash
PY=/Users/dreamyyxt/.workbuddy/binaries/python/envs/default/bin/python
cd /Users/dreamyyxt/WorkBuddy/2026-10-05-12-31-27

# 最简：素材文件夹直接出片
"$PY" workbench/tools/volc-mediakit.py \
    --media "第五季图片/品牌片素材" \
    --out "outputs/云端成片.mp4"

# 加 BGM + 控制每张图停留时长
"$PY" workbench/tools/volc-mediakit.py \
    --media ~/Desktop/拍摄/1013 \
    --duration 2.4 \
    --music ~/Music/bgm.mp3 \
    --out "outputs/1013-成片.mp4"
```

**素材命名决定顺序**，建议 `01_xxx.jpg` / `02_xxx.mp4` 这样加数字前缀。
支持 `.jpg .jpeg .png .webp` 和 `.mp4 .mov .m4v`。

## 三、它做了什么

| 步骤 | 云端能力 | 效果 |
|---|---|---|
| 1 | 本地上传 | 素材传到云端，拿到 `mediakit://` 引用 |
| 2 | 图片转视频 | **连续的多张图自动合成一段动态视频**，每张配镜头运动 |
| 3 | 视频拼接 | 所有段（含你拍的视频）拼成一条，**接缝处自动加转场** |
| 4 | 本地混音 | BGM 用本机 ffmpeg 混入，**不产生云端费用** |

关键点：**图片不再是"死图"** —— 每张都会缓慢推近/平移，段与段之间是真正的转场特效（不是硬切）。
这正好补上你之前说的「排版没意思」。

## 四、参数速查

| 参数 | 说明 |
|---|---|
| `--media` | **必填**，素材文件夹 |
| `--out` | **必填**，输出 mp4 路径 |
| `--duration` | 每张图片停留秒数，默认 `3.0` |
| `--music` | BGM 文件，本地混入 |
| `--music-volume` | BGM 音量，默认 0.35 |
| `--transitions` | 转场 ID，逗号分隔（默认 `1182358,1182369,1182375`） |
| `--animations` | 图片镜头动画（默认 `zoom_in,zoom_out,move_left,move_right` 循环） |
| `--no-animation` | 图片不加镜头动画 |
| `--upload-only` | 只上传素材不渲染（排查用） |
| `--check` | 自检 Key |

## 六、费用

剪辑工具按 **输出分辨率** 折算，1080P 系数 6：

```
单价 = 6 × 0.01 元/分钟 = 0.06 元/分钟
```

| 成片时长 | 费用 |
|---|---|
| 20 秒 | 约 **0.02 元** |
| 1 分钟 | 约 **0.06 元** |
| 100 条 20 秒 | 约 **2 元** |

批量做也基本可以忽略。输出链接 24 小时内有效，脚本会自动下载到本地。

## 七、和另外两条路的关系

| 方案 | 解决什么 | 成本 |
|---|---|---|
| **本工具（云端 MediaKit）** | 图片动起来 + 专业转场 + 拼接 | 几分钱/条 |
| 剪映草稿生成器 | 进剪映人工精修、加字幕贴纸 | 免费 |
| 本地预览成片 | 快速验收节奏 | 免费 |

**建议流程**：素材 → 本工具出云端成片（拿到转场和镜头运动）→ 需要改字幕/加贴纸时再进剪映。
或者反过来：先用剪映草稿生成器排好字幕，导出后再用本工具做画质增强。

## 八、常见问题

**报「鉴权失败」？**
Key 不对，或者该 Key 没开通 AI MediaKit。去
https://console.volcengine.com/imp/ai-mediakit/settings 重新复制一个。

**报「DownloadFailed」？**
素材链接云端拉不到。用本工具的 `--media` 走上传流程，不要手工传外链。

**图片是竖版但出来是横版？**
云端以第一张图的尺寸为基准。素材统一成竖版 1080×1920 最稳。

**想要卡点（画面跟着音乐节拍切）？**
把每张图的 `--duration` 设成音乐的节拍间隔即可。等确定了 BGM，
可以让助手帮你分析节拍点，再自动生成对应的时长列表。
