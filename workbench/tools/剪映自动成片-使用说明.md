# 剪映草稿自动生成 · 使用说明

一句话：**把素材丢进文件夹 → 跑一下 → 剪映里多出一份排好的草稿，微调后导出。**

不用手动摆片段、不用手打字幕、不用加片尾。工作台里的分镜脚本写多少段，
时间轴上就排多少段，字幕直接来自脚本的口播。

---

## 一、准备素材

新建一个文件夹（比如 `~/Desktop/拍摄/1013`），把这次要剪的图片和视频丢进去。

**命名决定顺序**，所以建议加数字前缀：

```
01_客人手部特写.jpg
02_甲面细节.mp4
03_门店花艺角落.jpg
04_成品展示.mp4
```

- 支持：`.jpg .jpeg .png .webp`（图片）、`.mp4 .mov .m4v`（视频）
- **素材不用和分镜数量一样**：少了会循环复用，多了会忽略后面多余的
- 视频比该段分镜长时会自动裁到分镜时长（`--no-trim-video` 可关掉）

## 二、跑一下

**方式 A（推荐）**：双击 `一键生成剪映草稿.command`，把素材文件夹拖进去，回车。
还会让你选脚本、选 BGM，一路回车即可。

**方式 B（命令行）**：

```bash
PY=/Users/dreamyyxt/.workbuddy/binaries/python/envs/default/bin/python
cd /Users/dreamyyxt/WorkBuddy/2026-10-05-12-31-27/workbench/tools

# 看有哪些脚本可用
"$PY" make-jianying-draft.py --list-scripts

# 用最新一条脚本生成
"$PY" make-jianying-draft.py --media ~/Desktop/拍摄/1013

# 指定脚本 / 加 BGM / 自定义草稿名
"$PY" make-jianying-draft.py --media ~/Desktop/拍摄/1013 \
    --script-id 32 --bgm ~/Music/bgm.mp3 --draft-name "备婚新娘-1013"

# 先不装进剪映，导出到普通文件夹看效果
"$PY" make-jianying-draft.py --media ~/Desktop/拍摄/1013 --no-install
```

跑完打开（或重启）**剪映**，草稿列表里就能看到它。

## 三、生成出来的草稿长什么样

| 轨道 | 内容 |
|---|---|
| 主画面 | 按分镜顺序排好的图片/视频，段与段之间自动加**叠化**转场 |
| 口播字幕 | 直接取脚本「口播」那一列，白字黑描边、贴底居中 |
| 大字贴纸 | 取脚本「字幕/贴纸」列里的字幕文案，贴在画面上方 |
| BGM | 可选，自动铺满全长，1 秒淡入 2 秒淡出，音量 0.28 |
| 片尾 | 品牌色底 + 店铺名 / 地址 / 地铁 / 营业时间（自动从「店铺档案」读） |
| 封面 | 自动从第一段素材生成 `draft_cover.jpg`（图片直接裁切；视频抽首帧），草稿列表里能直接看到画面 |

画布固定 **1080×1920**（抖音 / 小红书竖版）。

生成的草稿文件夹里会有 4 个文件，其中两个主文件是**内容相同**的：
`draft_info.json`（剪映 11.x 认这个）+ `draft_content.json`（旧版名，兼容用）。
两个都写，是为了让新旧版本剪映都能正确读到时间轴。

## 四、参数速查

| 参数 | 说明 |
|---|---|
| `--media` | **必填**，素材文件夹 |
| `--script-id` | 用哪条脚本，默认最新一条 |
| `--draft-name` | 草稿名，默认「日期_账号_标题」 |
| `--draft-dir` | 剪映草稿目录，默认自动探测 |
| `--out` / `--no-install` | 生成到普通文件夹，不装进剪映 |
| `--bgm` | 背景音乐文件 |
| `--bgm-volume` | BGM 音量，默认 0.28 |
| `--transition` | 转场时长，默认 0.35s |
| `--endcard` / `--no-endcard` | 片尾秒数（默认 3s）/ 不要片尾 |
| `--max-shots` | 只做前 N 个分镜 |
| `--dry-run` | 只解析分镜、不写草稿 |

## 五、常见问题

**草稿列表里没看到？**
打开剪映 → 右上角齿轮 → 全局设置 → 看「草稿位置」是不是
`~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft`。
如果不是，用 `--draft-dir <你的路径>` 指定。然后重启剪映。

**草稿列表里显示 `0.0B / 00:00`、封面是黑的？**
这是**列表索引**没读到内容，不是草稿坏了。原因有两个：剪映 11.x 的主草稿文件叫
`draft_info.json`（旧名叫 `draft_content.json`），以及列表要读的时长/大小/封面三个字段是空的。
生成器现在已经自动处理这两件事，所以**新生成的草稿不会再出现**。
如果是旧草稿，重新生成一份即可；实在要抢救，就是给草稿文件夹补上 `draft_info.json`，
并更新 `root_meta_info.json` 里那一条的 `tm_duration`、`draft_timeline_materials_size`、`draft_cover`。

**片尾文案要改？**
改工作台「设置 → 店铺档案」里的地址 / 交通 / 营业时间，下次生成自动生效。

**字幕太长挤在一行？**
脚本里一段口播别写太长；或者生成后在剪映里拆成两句。

**想先看分镜排得对不对、不生成文件？**
加 `--dry-run`。

## 六、原理与边界

- 靠开源库 `pyJianYingDraft` 直接写出剪映的草稿工程文件，**不调用剪映本身**，
  所以不吃配置、秒出、可以批量。
- 字幕时间轴来自脚本里的分镜表；**脚本写得越细，草稿排得越准**。
- 这一步只做「装配」：拼接、裁切、转场、字幕、片尾、BGM。
  挑镜头品味、节奏快慢，还是得你在剪映里过一眼。
- 依赖：`pyJianYingDraft` / `pymediainfo` / `pillow` / `imageio-ffmpeg`，
  已装在 `/Users/dreamyyxt/.workbuddy/binaries/python/envs/default`。
  其中 `imageio-ffmpeg` 自带一份 ffmpeg，用来抽视频首帧做封面，**不需要另外装系统 ffmpeg**。
