# 剪映「模板换素材」引擎 · 使用说明

**一句话**：把一份现成的剪映草稿当模板，自动换成你的素材，
模板的**版式 / 动画 / 转场 / 音乐 / 卡点全部原样保留**，输出一份新草稿。

工具：`workbench/tools/template-swap.py`

---

## 一、先说清楚一个硬门槛（很重要）

**剪映 6.0 版本之后，草稿文件被加密了。**

- 加密算法：AES-256
- **每份草稿一把独立密钥**
- 密钥存在剪映自己的内部数据库里，不落在外面的文件里

这意味着：**「你在剪映里套好一个模板、保存成草稿，然后让我读取它」这条路走不通。**
我实测过本机的草稿目录——凡是被剪映打开并保存过的草稿，根目录的
`draft_info.json` 已经变成一串加密乱码，只有在 `draft_content.json`
还留着明文时才能读。

社区有工具（`jy-draftc`，Windows 端）能做到解密，靠的是调用剪映自己的
`videoeditor.dll` 里的加解密函数。**Mac 版没有对应的可用方案**，不建议在这上面投入。

**反过来的方向是通的**：剪映**能正常读取明文草稿**。
我们现在给剪映生成的草稿就是纯明文的，你能正常打开看到时间轴——
只是因为一打开、一保存，剪映就把它加密了。

> 结论：**模板必须来自「明文草稿」，不能来自「剪映自己保存的草稿」。**

---

## 二、那模板从哪来？三条路

### 路 A · 我们自建模板（推荐，全自动、零成本）

用 `pyJianYingDraft` 自己搭一套第五季专属模板草稿（竖版 / 转场 / 排版字幕 /
BGM 卡点 / 片尾卡），存进剪映。之后换素材就是一条命令，30 秒出一份新草稿。

- ✅ 完全可控，批量，不吃剪映的加密
- ✅ 素材按音乐节拍自动切，卡点是算出来的不是手拉的
- ⚠️ 花字、贴纸、特效的华丽度比不上剪映官方模板

### 路 B · 用剪映的模板（半自动，保留设计感）

你在剪映里挑一个对味的模板套一次，然后**在剪映里「保存为我的模板」**。
以后每次出片：

1. 我按模板的槽位把素材**切好、按序号命名好**（这一步我全自动）
2. 你在剪映里套用模板 → 全选导入 → 导出

一次大约 1–2 分钟。设计感是剪映专业水平，代价是每次要手点导入。

### 路 C · 现成的明文草稿包

网上有一些分享的**剪映模板草稿包**（明文 JSON，多为旧版或 Windows 版）。
拿到这类草稿包，可以直接用本工具换素材。质量参差、注意版权，仅作备选。

## 三、怎么用

### 1) 先看有哪些草稿可以当模板

```bash
cd /Users/dreamyyxt/WorkBuddy/2026-10-05-12-31-27
PY=/Users/dreamyyxt/.workbuddy/binaries/python/envs/default/bin/python
$PY workbench/tools/template-swap.py --all-drafts
```

输出会标出每份草稿是 **✅ 明文可读** 还是 **🔒 加密读不了**。

### 2) 看模板需要几段素材

```bash
$PY workbench/tools/template-swap.py --template "模板名" --list
```

会打印每个槽位的：序号、入点、时长、类型（图片/视频）、尺寸、原素材名。
**跑这一步最省事**——照着它的数量和时间准备素材就行。

### 3) 换素材，生成新草稿

```bash
# 装进剪映（剪映要完全退出，Cmd+Q）
$PY workbench/tools/template-swap.py \
    --template "模板名" \
    --media ~/Desktop/素材/1013 \
    --out-name "客片-1013"

# 或者先导出到普通文件夹看看，不装进剪映
$PY workbench/tools/template-swap.py \
    --template "模板名" --media ./素材 --out-dir ./out
```

### 参数速查

| 参数 | 说明 |
|---|---|
| `--template` | 模板草稿名，或完整路径 |
| `--list` | 只列槽位，不生成 |
| `--all-drafts` | 列出本机所有草稿 + 明文/加密状态 |
| `--media` | 素材文件夹，或逗号分隔的文件列表（**顺序 = 槽位顺序**） |
| `--out-name` | 新草稿名（装进剪映用这个） |
| `--out-dir` | 输出到普通文件夹，不装进剪映 |
| `--fill` | 素材不够时：`loop` 循环（默认）/ `hold` 重复最后一张 / `trim` 剩下的空着 |
| `--track-index` | 有画中画等多条视频轨时，指定换哪一条 |
| `--yes` | 同名草稿直接覆盖 |
| `--dry-run` | 只打印计划，不写文件 |

## 四、它到底改了什么（原理）

剪映草稿里，**「素材」和「时间轴上的片段」是分开存的**：

```
materials.videos[]      素材本身    →  路径 / 尺寸 / 时长
tracks[].segments[]     时间轴片段  →  位置 / 时长 / 转场 / 动画 / 构图
```

片段只用一个 `material_id` 指向素材。所以：

**只换素材的指向，片段上挂着的转场、动画、特效、字幕时间点，一个都不会动。**

实测对比（9 段素材的模板 → 换完）：

| 项目 | 结果 |
|---|---|
| 片段数 | 9 → 9 |
| 时间轴位置与时长 `target_timerange` | **100% 不变** |
| 转场 / 动画引用 `extra_material_refs` | **100% 不变** |
| 构图 `clip`（缩放 / 位移 / 旋转） | **100% 不变** |
| 文字轨 | **完全一致** |
| 转场材料（叠化 0.35s） | **完全一致** |
| 总时长 / 帧率 | 58.00s / 30fps → 不变 |
| 素材指向 | shot_1.jpg → 01_open.mp4 … 逐槽替换 |

音乐和卡点也在音频轨 / 片段时长里，同样不受影响。

## 五、常见问题

**Q：素材比槽位短怎么办？**
工具会逐条告警。默认表现是画面在最后一帧停住。
经验值：**素材时长 ≥ 槽位时长**最省心；拍素材时宁可拍长一点。

**Q：素材会被复制走吗？**
不会，草稿直接引用原路径。**所以别移动或删除素材文件**，否则剪映里会丢素材。

**Q：生成后剪映里看不到 / 显示 0.0B 00:00？**
草稿列表是剪映**启动时**读一次索引。请先 `Cmd+Q` 完全退出剪映，再打开。
如果还是不行，把剪映退出后告诉我，我补一次索引。

**Q：为什么工具说我的模板「加密，读不了」？**
见第一节。这份草稿已经被剪映保存过了。只能换一份明文草稿当模板，
或者等路 A 的自建模板做好。

**Q：`--out-dir` 输出的那几份文件是什么？**

| 文件 | 作用 |
|---|---|
| `draft_content.json` / `draft_info.json` | 草稿本体（两份内容相同，剪映新旧名字都认） |
| `draft_meta_info.json` | 草稿元信息（时长 / 大小 / 封面） |
| `draft_cover.jpg` | 列表封面 720×1280 |

把它整个拷进 `~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/` 就能在剪映里看到。
